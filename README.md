# Interactive Corporate Sales & Industry Analysis
### ACC102 Mini Assignment – Track 4 (Interactive Data Analysis Tool)

## Project Purpose
This project is an interactive data analysis dashboard built with Streamlit. It allows users to explore, filter, and visualize corporate sales data and industry distribution without coding knowledge. The tool supports business analysis, data inspection, and quick insight generation for students and entry-level business users.

## Dataset Information
- Data includes 5 major global companies: Apple, Microsoft, Google, Amazon, Meta
- Variables: company_name, industry, sales
- Data quality: No missing values, fully clean and ready for analysis
- Source: Simulated business dataset for educational use

## Core Features
- Display dataset structure and basic overview
- Check missing values automatically
- Show descriptive statistics for sales
- Interactive industry filter (dropdown selection)
- Interactive sales range filter (slider control)
- Real-time bar chart: Sales by company
- Pie chart: Industry distribution proportion

## Tools & Libraries Used
- Python 3
- pandas: Data loading, filtering, statistics
- matplotlib: Visualization (bar chart, pie chart)
- streamlit: Interactive web interface

## How to Run Locally
1. Clone or download this repository
2. Install required packages:
   pip install -r requirements.txt
3. Launch the app:
   streamlit run app.py

## Project Structure
- app.py: Main Streamlit dashboard
- README.md: Project documentation
- requirements.txt: Dependency list
- sales_analysis.ipynb: Python analysis notebook
