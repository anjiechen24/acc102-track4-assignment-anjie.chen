# ACC102 Track 4 Interactive Data Analysis Tool
## Project Introduction
This project is an interactive business data analysis application completed for ACC102 Track 4 assignment.
It focuses on corporate sales and industry financial data analysis, and provides interactive data viewing function for users.

## Data Analysis Workflow
The complete Python data analysis process includes:
1. Import and load the original dataset
2. Data cleaning and missing value inspection
3. Descriptive statistical data analysis
4. Interactive data filtering and screening
5. Data visualization and result analysis

## Technology & Dependencies
This program is built with Python, using Pandas for data processing, Matplotlib for chart visualization, and Streamlit for interactive web tool development.
All required libraries are listed in `requirements.txt`.

## How to run the application
1. Open Anaconda Prompt
2. Switch to desktop folder
